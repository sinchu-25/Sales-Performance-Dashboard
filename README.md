# Sales Performance Dashboard

## Overview
An interactive Power BI dashboard built using the Superstore dataset to analyze sales performance.

## Screenshot
Screenshot 2026-08-01 002128.png
## KPIs
- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Total Discount

## Dashboard Features
- Sales by Region
- Sales by Category
- Sales by Sub-Category
- Sales by Segment
- Sales by State (Map)
- Interactive slicers for Region, Segment, and Category

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

- Data Cleaning
- Data Modeling
- Dashboard Design
